# Artwork System — "Line of S"

모든 요소는 "What must this visual prove?"에 답해야 한다(`visual-direction.md` §4). 한 프로젝트 안에서 Motif는 **The Line** 1개와 보조 장치 《 》 1개만 쓴다.

## Main Motif — The Line
- 두께: Desktop 12 · Mobile 8
- 선 끝: 둥근 cap
- 색: 기본 **Ink (#121212)** 단색. 분관 컬러는 선이 아니라 **정거장(Station)**에만 쓴다.
  - 이유: 라임·앰버·스카이는 Paper 위 대비가 1.1–1.8이라 선으로 쓰면 그래픽 대비 3:1을 충족하지 못한다.
- 역할은 세 가지다: ① 정체성(S의 흐름) ② 길찾기(분관 필터) ③ 이야기(목록 → 상세 → 관람정보로 이어지는 흐름)

## Shape Language
- **구성 단위**: 수평·수직 직선 + **90° 원호**(반지름 = 선 두께 × 4). S는 원호 2개를 반대 방향으로 연결해 만든다.
- **금지**: 임의의 베지어 곡선, 대각선, 지그재그(Whitney W와 구분). 모든 형태는 격자에서 재현 가능해야 한다.
- **Station**: 지름 = 선 두께 × 3의 원. 분관 컬러로 채우고 Ink 2px 외곽선을 둔다.
  - 선택 상태: 지름 × 1.5, 외곽선 없이 색을 채우고 Ink 체크 표시
- **Tag**: 모서리 반경 0의 직사각형. 분관 컬러 면 + on-color 텍스트(`design-tokens.md`).

## Color Behavior
| 원칙 | 규칙 |
|---|---|
| 면 우선 | 분관 컬러는 **면(fill)으로만** 쓴다. 텍스트 색이나 가는 선으로 쓰지 않는다 |
| 한 화면 한 분관 강조 | 목록은 여러 분관 색이 공존한다. 상세는 **해당 분관 1색 + Ink + Paper**로 제한한다 |
| 색은 정보 | 색이 있으면 반드시 분관명 텍스트가 동반된다(색각 이상 대응) |
| 작품 보호 | 실제 작품 이미지에는 **색 오버레이, 듀오톤, 블렌드를 금지**한다. 선과 색은 이미지 **바깥**에서만 쓴다 |

## Layering
- **순서**(아래 → 위): Paper 배경 → 분관 컬러 면 → 이미지·커버 → The Line → 텍스트
- **텍스트와의 관계**: 선은 텍스트 **뒤로 지나가지 않는다**. 텍스트 블록 사이의 여백으로 지나간다(가독성).
- **선이 가를 수 있는 곳**: 선이 화면 가장자리로 나가는 Full-bleed는 허용한다. 목록 카드 그리드를 가로지르는 것은 금지한다(비교 방해).

## Texture
- 사용하지 않는다(단색 면과 선만). 근거: 인쇄 질감이 전할 의미가 없고, 모바일 성능과 가독성에 불리하다.

## Type Interaction
- **《 》**: Display 크기의 겹화살괄호를 제목 양끝에 둔다.
  - 괄호는 Ink, 폰트 Weight 400(가는 괄호)과 제목 Weight 900의 대비로 만든다.
  - 상세 Hero에서만 초대형으로 쓰고, 목록 카드에서는 본문 크기로 쓴다.
- **선과 타이포의 관계**: 선은 페이지 제목의 **베이스라인에서 출발**하거나, 사실 패널(기간·장소) 좌측 모서리에 **도착**한다.

## Composition
| 화면 | 구성 |
|---|---|
| 목록 헤더 | 좌측 정렬 Display 제목 + 그 아래를 **가로지르는 Line에 정거장 9개**(전체 + 8분관). 비대칭 — 선이 우측 가장자리 밖으로 나간다 |
| 목록 본문 | 규율 있는 12열 그리드, Line 없음 |
| 상세 Hero | 좌 7/12 《제목》 초대형 · 우 5/12 커버. Line이 헤더에서 내려와 **사실 패널로 들어간다**(S자 1회) |

## Variation Rules (조합 가능한 유한 요소)
**변수**
- 분관 컬러: 8색
- Line 경로 템플릿: `straight` / `S` / `L`
- Station 위치: 경로 위 균등 분할

**Cover Artwork** — 권리가 확보된 이미지가 없을 때의 전시 커버
- 분관 컬러 면
- Ink Line 조각(경로 템플릿 1개)
- 《 》 + 제목 첫 1–3음절
- 결과: **같은 분관이면 같은 색, 전시마다 다른 선 경로**
  - 경로 선택은 전시 ID 기반으로 결정적(deterministic)이어야 한다 — 무작위 금지

**Composition Family** — 2026-09-30 STEP 08 Refinement에서 추가
- 배경: Master Render에서 12개 커버가 "단색 + 비슷한 선 + 하단 제목"으로 반복된다는 문제가 확인됨.
- 해결: 같은 Line 모티프 안에서 4개 Family로 규칙적으로 변주한다. 새 모티프는 추가하지 않는다.

| Family | 선(두께·형태·위치) | 타이포 위치 | 성격 |
|---|---|---|---|
| F1 Horizon | 18 · 수평 직선 · 높이 40% | 하단 좌측 64 | 무게감, 안정 |
| F2 Descent | 10 · S자 하강 · 상단 → 중단 | 하단 좌측 64 | 흐름 |
| F3 Rise | 10 · L자 상승 · 하단 좌측 → 우측 세로 | **상단 좌측** 56 | 역방향, 여백 하단 |
| F4 Macro Arc | **36** · 대형 90° 호 · 좌하단 코너 | **상단 우측** 56 | 스케일 대비, 음의 공간 |

**배정 규칙** (결정적): 결과 그리드 위치를 기준으로 라틴 방진처럼 배정한다. 같은 행과 같은 열에 같은 Family가 오지 않는다.
- Desktop 4열: 1행 F1·F2·F3·F4 / 2행 F3·F4·F1·F2 / 3행 F2·F1·F4·F3
- 상세·모바일 썸네일: 목록에서 그 전시에 배정된 Family를 그대로 쓴다.

**공통 제약**
- 선은 고지 문구와 타이포 영역을 지나지 않는다.
- 고지 문구 "콘셉트 아트워크 · 공식 이미지 아님"은 모든 Family에 유지한다.

**금지**
- 새 모티프 추가(패턴, 별, 파형 등)
- 한 커버에 분관 색 2개
- 사진 위 텍스트 오버레이
