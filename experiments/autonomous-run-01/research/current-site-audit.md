## 4. Core Flow Audit — 현재 전시 탐색 → 비교 → 상세 확인

### 4-1. 목록
대상: `?whatsonMenuDivList=EX&whenType=FROM_TODAY`, Desktop 기본 창 크기

**선택된 필터** [F]
- 기본 선택 칩 **8개**: 전시, 문화행사, 서울미디어시티비엔날레, 서울사진축제, 현재, 어린이, 청소년, 성인
- 그런데 결과 12건은 **모두 "전시"** 라벨임 [F]
- 필터 패널은 기본으로 접혀 있음(`필터 보기 축소됨`) [F]

**결과** [F]
- 1페이지 12건, "1 / 2 페이지", "다음" 링크
- 정렬 컨트롤은 확인되지 않음

**카드** [F]
- 구성: 제목(strong), 유형 라벨 "전시", 분관명, 기간(YYYY/MM/DD~YYYY/MM/DD)
- 썸네일 `img`의 `alt=""`
- 제목 앞에 시리즈·기획 접두어가 붙음. 예: "2026년 한국 대표 조각가전 《…》", "유휴공간 프로젝트 전시 《…》", "서울시립 서서울미술관 플레이 라운지 《…》"
- 서울 분관이 아닌 "주캐나다한국문화원"(해외 순회) 항목이 같은 목록에 구분 없이 섞여 있음

**카드 링크** [F]
- `href="javascript:;"`
- 클릭하면 스크립트가 숨은 폼(`#scFrm`)에 `exNo`를 넣고 **POST로 제출**함
- 반면 상세는 GET(`/kr/whatson/exhibition/detail?exNo=1553791`)으로도 열림 [F]
- → 목록에서는 공유·새 탭 열기·비교용 URL이 노출되지 않음 [D]

**모바일 390×844** [F/D]
- 카드는 1열, 카드 높이 약 501–505px [F]
- 필터 영역부터 첫 카드까지 약 253px [F]
- 12건 목록 전체가 약 6,050px(뷰포트 약 7개 분량)을 넘어야 2페이지로 갈 수 있음 [D]
