## PDP 공통 구조 [VF]
경로(Men > 신발 > 러닝화) → 3D 보기 / 이미지 확대 → 상품명(한글) → 분류("남성 신발"/"남여공용 신발") → 찜하기·공유하기 → 가격(원) → 스타일 # → 쿠폰 및 혜택(쿠폰받기 · "카드혜택, 최대 6개월 무이자") → 후기 N개 → 색상(영문 대문자 컬러명 1개) → 사이즈(드롭다운 select "사이즈를 선택해 주세요", 품절은 "(품절)" 비활성) + 사이즈 가이드 → 총 상품 금액 → CTA
- CTA: 일반 상품 "장바구니 담기" + "바로구매" / 일부 상품 "로그인 후 구매 가능"(버튼 대신 문구)
- **컬러 썸네일 = 다른 PDP로 이동하는 링크**: PDP 하나 = 컬러웨이 하나. 색상 행에 같은 모델 다른 컬러의 썸네일이 있고, 누르면 별도 PDP(goods no)로 페이지가 바뀐다(예: 젤 님버스 28 → no 21900 · 21928 · 22687). 데스크톱·모바일 동일 [VF]
- **제품 상세 정보 표 5필드만**: 원산지 · 소재 · 아웃솔 소재 · 미드솔 소재 · 무게. Cushion · Heel Drop · Support · Goal 필드 없음 [VF]
- 그 아래: 맞춤 상품 추천 · 상품상세설명(이미지 중심 추정 [UV]) · 상품후기 · 고객님을 위한 추천 상품 · 제품정보 제공 고시 · 배송안내 · 반품안내
