# 문제 정의

## 문제 1: B2C/B2B 정보 혼재
TJ미디어 웹사이트는 일반 노래방 이용자(B2C)와 노래방 업주·비즈니스 파트너(B2B)의 정보가 동일한 구조 안에 혼재되어 있다.

- 영향: 각 사용자가 필요한 정보를 찾기 위해 불필요한 탐색을 거쳐야 한다.
- 해결 방향: `ia/sitemap-redesign.md`에서 B2C(`c-`)와 B2B(`b-`) 구조를 분리한다.

## 문제 2: 핵심 행동(곡 검색·음악 탐색)이 중심 경험이 아님
일반 사용자의 핵심 행동인 곡 검색과 음악 탐색이 웹사이트의 중심 경험으로 충분히 강조되지 않는다.

- 영향: 사용자가 사이트를 방문하는 주된 목적(곡 검색/탐색)을 수행하기 어렵다.
- 해결 방향: B2C 홈 화면(`c-home`) 최상단에 검색 진입점을 배치하고, 탐색(장르/인기곡/신곡) 섹션을 주요 콘텐츠로 재배치한다.
