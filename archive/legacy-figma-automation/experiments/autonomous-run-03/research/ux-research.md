## 관찰 요약 [F]
- 첫 진입: 상단에 공지 레이어 "새로운 날씨지도를 만나보세요…"와 "새로운 날씨지도 바로가기"(`/wnuri-map/html/map.html`), "24시간 동안 보지 않기 | 닫기"
- GNB 6개: 특보·예보 / 현재날씨 / 위험기상 / 수치일기도 / 기후·기후변화 / 지진·화산
- 본문 첫 줄: "전국특보 없음"
- "날씨" 탭(선택됨)의 구성 순서
  1. "지역을 검색하여 관심지역 등록 가능합니다." + 행정동검색
  2. 현재위치 링크(라벨 원문: "현재위찾기") + 기본 지역 1곳 + 관심지역 토글
     - 지역명은 기록하지 않음: 접속 위치에서 정해졌을 수 있음
  3. "지도 건너뛰기"(`#after-map`) · "날씨지도 닫기"
  4. 지도 레이어 링크 9개: 초단기강수예측, 특보, 어제, 1시간관측, 날씨/기온, 강수, 풍향/풍속, 현재날씨, 예보
  5. "날씨기호 설명", "날씨지도 새창열기", "09.30.(수) 21:00 갱신"
  6. 해상 지점 버튼 32개(풍속 m/s · 파고 m)
     - 1곳 풍속이 **"NaN m/s"**(내파수도)
     - 여러 곳이 "- m/s", "- m"
  7. 지점 39곳의 날씨 기호(이미지 alt "지점: 상태") + 기온
  8. 지도 이후: SNS 카드(옙TV·유튜브·엑스 — 엑스 카드는 "2026년 9월 28일 5시 기준 예보관 리포트"), 배너 3개, "전국" 탭, 외부 링크 12개
- 선택된 기본 지역의 **현재 기온·날씨·시간별 예보 텍스트는 스냅샷에서 찾지 못함**
  - 검색어 "시간별" 0건
  - "내일"은 SNS 카드 문장에만 있음
- 지도 레이어 중 어느 것이 선택된 상태인지는 스냅샷에 표시되지 않음 [U]

## 문제 정의 (3)

### P1. 지역은 보이지만, 그 지역의 날씨 요약이 보이지 않는다
- **OBSERVED FACT [F]**
  - 기본 지역과 관심지역 기능이 본문 맨 앞에 있다.
  - 그 지역의 현재 날씨·기온·예보 요약 텍스트는 접근성 트리에서 확인되지 않는다.
  - 지역 값은 지도 안 지점 목록(예: "서울: 구름많음" 22.1)으로만 읽을 수 있다.
- **POSSIBLE USER DIFFICULTY [H]**
  - "우리 동네 지금 날씨"를 알려면 지도에서 가까운 지점을 찾아야 할 수 있다.
  - 화면낭독 사용자는 요약을 얻기 어려울 수 있다.
- **DESIGN RESPONSE [P]**
  - 첫 화면 맨 위에 **지역 요약 카드**를 둔다: 지역 · 날씨 기호 + 텍스트 · 기온 · 갱신 시각.
  - 지도는 보조 진입점으로 내린다.
- **LIMITATION**
  - 지도 위에 시각적으로만 그려진 요약이 있을 수 있다(스크린샷 미확인 [U]).
  - 시간별 예보 수치는 수집하지 않았으므로 시안에서 "데이터 미수집" 상태로 둔다.

### P2. 지도 데이터가 순서상 먼저 오고, 값 표기에 오류가 노출된다
- **OBSERVED FACT [F]**
  - 지도 레이어 링크 9개, 해상 지점 32개, 지점 39개가 지도 이후 콘텐츠보다 앞에 있다.
  - "지도 건너뛰기" 링크는 제공된다(긍정적 관찰).
  - 한 지점의 풍속이 "NaN m/s"로 표시된다.
- **POSSIBLE USER DIFFICULTY [H]**
  - 지도를 쓰지 않는 사용자도 많은 지점 항목을 지나야 할 수 있다.
  - "NaN"은 일반 사용자가 이해하기 어려운 값이다.
- **DESIGN RESPONSE [P]**
  - "전국 지금" 화면을 지도 대신 **권역별 기호 목록**(텍스트 우선)으로 만든다.
  - 값이 없거나 잘못된 경우는 "자료 없음" 상태로 통일해 내부 값(NaN 등)을 노출하지 않는다.
- **LIMITATION**: 권역 분류(수도권·강원·충청·전라·경상·제주)는 이 프로젝트의 분류다 [P]. 원 페이지는 지도 위치로만 배치한다.

### P3. 지도 경험이 두 갈래로 안내된다
- **OBSERVED FACT [F]**
  - 첫 진입 공지가 "새로운 날씨지도"(별도 페이지)를 안내한다.
  - 같은 홈 본문에는 기존 날씨지도와 "날씨지도 새창열기"가 있다.
- **POSSIBLE USER DIFFICULTY [H]**: 어느 지도를 써야 하는지 헷갈릴 수 있고, 공지 레이어가 첫 화면 콘텐츠와 경쟁할 수 있다.
- **DESIGN RESPONSE [P]**
  - 공지는 콘텐츠를 가리지 않는 한 줄 배너로 바꾼다.
  - 지도 진입점은 "지도로 보기" 하나로 둔다.
- **LIMITATION**: 공지가 실제로 화면을 얼마나 가리는지는 스크린샷이 없어 확인하지 못했다 [U].
