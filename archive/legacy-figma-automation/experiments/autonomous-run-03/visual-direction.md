### 선택 근거 (A)
1. 실제 데이터(39곳 × 상태·기온)를 그대로 쓸 수 있는 표현이다 [D].
2. What must this visual prove? → **"이 지점의 지금 하늘은 어떤 상태인가."** 기호는 장식이 아니라 상태값 자체다.
3. 기호마다 상태 텍스트를 항상 붙인다. 모양·색만으로 전달하지 않는다.

## 3. Color [P]
기호 색은 그래픽 대비(3 : 1 이상)만 맞추고, 글자에는 쓰지 않는다. 대비는 WCAG 공식으로 수동 계산했다(도구 실행 없음).

| Token | 값 | 용도 | 대비(수동 계산) |
|---|---|---|---|
| `--sky-night` | #10203F | 히어로 배경(관측 시각 21:00 → 밤) | 흰 글자 ≈ 15 : 1 |
| `--paper` | #F6F4EE | 본문 배경 | ink ≈ 16 : 1 |
| `--ink` | #0E1726 | 본문 | — |
| `--ink-2` | #4A5568 | 보조 텍스트 | paper 위 ≈ 6.8 : 1 |
| `--on-night-2` | #B9C3D6 | 밤 배경 보조 텍스트 | night 위 ≈ 9.1 : 1 |
| `--glyph-sun` | #B87400 | 맑음 기호(밝은 배경) | paper 위 ≈ 3.4 : 1 (그래픽) |
| `--glyph-sun-night` | #FFC233 | 맑음 기호(밤 배경) | night 위 ≈ 10 : 1 |
| `--glyph-cloud` | #6B7A90 | 구름 | paper 위 ≈ 4.0 : 1 |
| `--glyph-overcast` | #46505F | 흐림 | paper 위 > 7 : 1 |
| `--glyph-rain` | #1F5FD6 | 비 | paper 위 ≈ 5.2 : 1 |
| `--accent` | #1F4FD1 | 링크·선택 | paper 위 ≈ 5.5 : 1 |

- 밤 배경 히어로는 관측 시각(21:00)에 근거한다 [D].
- 낮 시각 변형은 정의만 하고 제작하지 않는다 [P].

## 4. Typography [P · AESTHETIC PROPOSAL 포함]
- 한글: **Gothic A1**(Google Fonts) → 대체: Apple SD Gothic Neo, Malgun Gothic, sans-serif
- 숫자·라틴: **Space Grotesk** → 대체: system-ui
- 근거: 기온 숫자가 가장 큰 정보라 숫자 전용 서체로 크기 대비를 준다 [P].
- 서체 조합 자체는 AESTHETIC PROPOSAL이다. 기존 프로젝트 서체(Noto Sans KR · IBM Plex Mono · Pretendard)는 피했다.
- 크기: 12 / 14 / 16 / 18 / 20 / 24 / 32 / 40 / 48. Display 기온은 96(Desktop) · 72(Mobile)
- 오프라인에서는 웹 서체가 로드되지 않을 수 있고, 그때는 시스템 서체로 표시된다 [U].

## 5. Graphic Language — Glyph System [P]
| 상태(원 사이트 표기) | 기호 구성(24 그리드) | 색 |
|---|---|---|
| 맑음 | 원 1개 | sun |
| 구름많음 | 원 일부를 가리는 둥근 구름 | sun + cloud |
| 흐림 | 둥근 구름 2개 겹침 | overcast |

규칙
- 모든 기호 옆에 원 사이트의 상태 텍스트를 그대로 붙인다.
- 기호는 상태당 1개, 크기만 바뀐다(16 / 24 / 48 / 120).
- 장식용 변주는 없다.

## 6. Composition [P]
- **Desktop 우리 동네 지금**: 밤색 히어로 띠(지역 요약 · 대형 기온 · 120 기호) → 근처 지점 3개 → 시간별 예보 모듈(미수집 상태) → 특보·지도 진입
- **Desktop 전국 지금**: 상단 상태 분포 막대(28 / 9 / 1 / 1, 실제 개수) → 권역 6개를 열로 묶은 기호 목록
- **Mobile**: 같은 순서로 세로 스택. 전국 지금은 권역별 접힘 없이 2열 목록(스크롤)
- AESTHETIC PROPOSAL: 히어로의 큰 기호를 오른쪽으로 화면 밖까지 걸치는 배치
