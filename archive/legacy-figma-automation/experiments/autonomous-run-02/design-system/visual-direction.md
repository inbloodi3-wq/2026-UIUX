### 선택 근거 (B)
1. **What must this visual prove?** — "지금 공기 속 입자가 많은가 적은가." Artwork가 장식이 아니라 측정값 그 자체를 보여 준다(Semantic Visual Rule).
2. 서비스의 핵심 대상(입자)과 용어 혼란(P2)을 한 장치로 다룬다. PM10은 큰 점, PM2.5는 작은 점, 오존은 속이 빈 고리로 **이름과 형태를 일치**시킨다.
3. 기존 포트폴리오에 없는 표현(생성형 데이터 Artwork + 정보 디자인)이다.
4. 한계
   - 점 밀도는 **설명용 시각화**이며 실제 입자 수나 물리량이 아니다. 화면에 "1점 = 1㎍/㎥" 같은 기준을 항상 표기한다.
   - 점이 많은 날(매우나쁨)은 성능·가독성 부담이 있어 상한을 둔다.

## 3. Color [P]
색은 **등급 전달용**으로만 쓴다. 색만으로 전달하지 않는다: 등급 이름, 수치, 점 밀도를 항상 함께 둔다.

| Token | 값 | 용도 | 대비(계산) |
|---|---|---|---|
| `surface-fog` | #EEF1EF | 페이지 배경(옅은 안개) | ink 대비 15.74 |
| `surface-card` | #FFFFFF | 카드 | — |
| `text-ink` | #12181C | 본문·숫자 | 흰색 위 약 17 |
| `text-ink-2` | #4A5358 | 보조 텍스트 | 흰색 7.87 / fog 6.92 |
| `grade-good` | #2563D9 | 좋음 — 점·배지 | 흰색 5.43 |
| `grade-moderate` | #0F7A54 | 보통 | 흰색 5.34 |
| `grade-bad` | #9A5800 | 나쁨 | 흰색 5.57 |
| `grade-verybad` | #C8321E | 매우나쁨 | 흰색 5.34 |
| `grade-nodata` | #5E676C | 데이터 없음 | 흰색 5.78 |
| `grade-*-tint` | #DCE7FB / #D5EFE4 / #FBE9C8 / #F9DAD4 | 판단 카드 배경 | 틴트 위 텍스트는 `text-ink`만 사용(등급색 텍스트는 4.07–4.67로 부족) |

- 파랑·초록·노랑계·빨강의 순서는 국내 대기질 안내에서 익숙한 배열이라는 **가설 [H]**에 따른 것이다. 공식 색상값은 확인하지 않았다.
- 배지는 등급색 면 + 흰 글자로 만든다(≥ 5.3 : 1).

## 4. Typography [P]
- 한글: Noto Sans KR
  - AUTORUN_01에서 Figma 런타임 로드가 확인된 서체다. Pretendard는 플러그인에서 로드되지 않는다.
- 숫자: 표 형식 숫자(tabular)를 쓰는 고정폭 계열을 1순위로 한다(후보: IBM Plex Mono).
  - **Figma 제작 전 `listAvailableFontsAsync`로 가용성 확인 [U]**. 없으면 Noto Sans KR Bold로 대체한다.
- 크기
  - 본문·UI: 12 / 14 / 16 / 18 / 20 / 24 / 28 / 32 / 40 / 48. 기존 승인 스케일과 동일한 짝수 체계다.
  - 대형 수치 Display: Desktop 96, Mobile 64. 스케일 밖의 예외로, 판단 숫자 1개에만 쓴다.
- 원칙
  - 가장 큰 활자는 제목이 아니라 **판단(등급)과 수치**다.
  - 단위(㎍/㎥, ppm)는 수치의 40% 크기로 붙인다.
  - 기준 시각은 항상 caption(12–14)으로 수치 바로 아래 둔다.

## 5. Artwork System — Particle Field [P]
| 항목 | 규칙 |
|---|---|
| Core motif | 입자 1종류(원). 추가 모티프 없음 |
| Shape language | PM10 = 채운 원 Ø12 · PM2.5 = 채운 원 Ø3 · 오존 O₃ = 빈 고리 Ø10 / 선 1.5. PM 크기 비율 4 : 1은 "10 vs 2.5"라는 이름을 따른다(mini 필드는 Ø8 / Ø2로 같은 비율 축소) |
| 밀도(Density) | 100×100px 기준 영역당 PM: 1점 = 1㎍/㎥ · O₃: 1고리 = 0.002ppm. 한 필드의 점 수 상한은 300. 상한을 넘으면 "상한 도달" 표기 |
| 배치 | 고정 seed 의사난수 + 최소 간격(겹침 방지). 같은 측정소·같은 시각이면 같은 배치(재현 가능) |
| Color behavior | 점은 해당 항목 등급색. 배경은 `surface-fog`. 판단 카드에서는 가장 나쁜 항목의 틴트 |
| Typography interaction | 대형 수치 주변은 입자가 없는 **clear zone**(텍스트 영역 + 24px) |
| Composition rule | Hero 필드는 화면 가장자리까지 bleed(Desktop 우측 7/12, Mobile 상단 전폭). 예보는 날짜별 small multiples(같은 크기 필드 × 3일) |
| Variation rule | 모양·색은 데이터에서만 바뀐다. 장식적 변주는 없다 |
| 표기 의무 | 필드마다 "시각화 기준: 1점 = 1㎍/㎥(100×100 영역)" caption |

### 5-1. 제작 단계 개정 (2026-09-30 Figma Production — 데이터 정확성 우선)
사전 계획을 그대로 쓰면 수치를 오해할 수 있는 부분이 있어, 제작 전에 규칙을 좁혔다. 위 5장 표보다 이 절이 우선한다.

| 항목 | 계획 | 개정 | 이유 |
|---|---|---|---|
| 필드 구성 | 3항목을 한 필드에 겹침 | **항목별 필드 3개로 분리**(같은 크기) | PM과 오존은 단위가 달라 한 장면에서 개수를 비교하면 오해가 생김. PM10과 PM2.5는 같은 공기를 서로 다른 입자 크기 기준으로 잰 값이라, 겹쳐 그리면 두 양을 더한 것처럼 보일 수 있음(PM2.5가 PM10 범위에 포함된다는 점은 일반 정의이며 이 프로젝트 출처로 기록하지 않음 [I]) |
| 크기 | Ø12 / Ø3 | **Desktop Ø16 / Ø4 · Mobile Ø12 / Ø3**(둘 다 4 : 1) · 오존 고리 Desktop Ø10 / Mobile Ø8 | Render에서 Ø3이 거의 보이지 않음(Master QA 결함) |
| 오존 단위 | 고리 1개 = 0.002 ppm | **1개 = 0.001 ppm, 정수 반올림**(0.0544 → 54) | 최소 단위를 키워 규칙 설명을 단순하게 함 |
| 밀도 기준 | 100×100 영역당 | **필드 1칸당 개수 = 값**(상한 300, 초과 시 ‘상한 도달’) | 필드 크기가 화면마다 달라 면적 기준이 무의미해짐 |
| 예보 화면 | mini field | **입자 = 항목 구분 아이콘만**(중립색, 개수 의미 없음) | 예보는 등급만 발표되고 수치가 없음 → 개수로 나타낼 값이 없음 |
| 판단 카드 이름 | 통합 판단 | **“지금 가장 높은 등급”** | 공식 통합대기환경지수(CAI)와 혼동 방지. 산정 방식이 다름 |

- **공식 등급 기준과 제안 팔레트 구분** [F]: 에어코리아 예보 페이지의 ‘예보등급 및 행동요령’ 표(S8)에 예보 등급 구간이 원문으로 있다.
  - PM10 0–30 / 31–80 / 81–150 / 150 초과 (㎍/㎥, 1일)
  - PM2.5 0–15 / 16–35 / 36–75 / 75 초과 (㎍/㎥, 1일)
  - O3 0–0.0300 / 0.0301–0.0900 / 0.0901–0.1500 / 0.1500 초과 (ppm, 1시간)
  - 화면에는 이 구간을 원문 그대로 싣고, **배지 색만 제안 팔레트**라고 표기했다.
  - 측정값의 등급은 에어코리아가 표시한 값을 그대로 쓴다. 측정 등급 기준은 확인하지 않았으므로 측정값을 예보 구간 위에 표시하지 않는다.

## 6. Composition [P]
- **Desktop 홈**: 비대칭 5/7
  - 좌 5/12: 판단 카드(등급·행동 한 줄·기준 시각·측정소) + 3개 항목 수치
  - 우 7/12: Particle Field bleed
  - 그 아래: 오늘·내일·모레 small multiples
- **Desktop 예보**
  - 상단: 내 지역 3일 × 3항목 매트릭스(행 = 항목, 열 = 날짜)
  - 그 아래: 원인 분석 요약
  - "전국 보기" 펼침 표(19권역)
  - "전문 정보"(예측모델 이미지 자리) 접힘
- **Mobile**: 같은 우선순위 유지(Reflow)
  - 판단 카드 → 항목 3개 → 필드 띠(390×200) → 3일 요약 → 자세히
  - 예보는 날짜 탭 대신 **세로 스택** — 3일을 스크롤 한 번에 비교
- 그리드: Desktop 12col / margin 96 / gutter 24 · Mobile 4col / margin 20 / gutter 12
  - Foundation Grammar Range 안에서 선택
