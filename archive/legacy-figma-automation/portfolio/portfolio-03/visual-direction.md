# Visual Direction — PORTFOLIO_03 (ASICS, Unofficial Personal Redesign)

- 모든 색·서체·그래픽은 **DESIGN PROPOSAL**이다. ASICS 공식 아이덴티티를 재현하지 않는다.
- ASICS 로고는 쓰지 않는다. 브랜드명은 일반 텍스트로만 표기한다.
- 근거 없는 순수 미감 선택은 **AESTHETIC PROPOSAL(AP)**로 표시한다.

## 피해야 할 수렴
White-first Minimalism · Quiet Luxury · 큰 여백 + 작은 검은 텍스트 · 정적 카드 그리드 반복 · 에디토리얼 패션 레이아웃
→ 실제 ASICS 사이트는 흰 배경 중심이다 [F]. 리디자인은 어두운 표면과 채도 높은 색을 **기본 언어**로 삼는다. 흰색은 상품 스테이지에만 쓴다.

## 세 방향

### A. PACE LANES — 목표로 달리는 트랙
| 항목 | 정의 |
|---|---|
| CORE IDEA | 실제 Goal 값(Faster / Further)을 트랙 레인으로 만든다. 레인이 탐색의 첫 갈림길이고, 모델은 레인 위의 주자다 |
| BRAND CONNECTION | ASICS 상품 데이터의 Goal·Cushion·Support 필드가 이미 러닝 성능 언어다 [F] |
| UX CONNECTION | P1: 홈과 컬렉션을 Goal 레인으로 나누고, 레인 안에서 스펙 칩으로 비교한다 · P3: 레인 색이 모바일 고정 구매 바까지 이어진다 |
| TYPOGRAPHY | 압축·이탤릭 디스플레이(후보 Barlow Condensed ExtraBold Italic) + 수치 전용 무게(239 g, 8 mm) · 본문 Inter |
| COLOR | 트랙 블랙 표면 + 레인 색 2개(Faster = Orange Glow 계열, Further = Energy Aqua 계열) + Illuminate Yellow(선택·CTA) |
| PRODUCT ARTWORK | 자체 제작 측면 실루엣 벡터. −8° 기울여 레인 경계를 넘게 겹친다(속도감) |
| COMPOSITION | 12° 사선 레인 밴드로 섹션을 전환한다. 비대칭 · 겹침 · 거대한 수치 타이포 |
| GRAPHIC SYSTEM | 레인 밴드(번호 01/02) · 사선 섹션 컷 · 스펙 칩 · 진행 방향 화살표(CTA에만) |
| RISKS | 사선과 레인이 SeMA의 '선' 모티프와 비슷해 보일 위험 → 가는 선이 아니라 **넓은 색 밴드 + 번호**로 구분 · 이탤릭 남용 시 가독성 저하 → 디스플레이에만 |
| FEASIBILITY | Figma 벡터·오토레이아웃으로 구현 쉬움. 서체 가용성은 제작 전 확인 |

## DIRECTION SELECTED: **A. PACE LANES**
- **WHY**: 세 문제 중 두 개(P1 탐색 비교, P3 모바일 구매)에 직접 대응하는 그래픽 시스템이다. 그 근거가 실제 데이터 필드(Goal)에 있다.
- **검증 보완**: Goal 필터 값은 실제로 두 개(Further 211 · Faster 28)다 [F]. 레인 2개는 실제 분류와 일치한다.
  - 수가 크게 다르므로 레인 헤더에 상품 수를 표시하고, Further 레인 안에서 Cushion · Pronation으로 다시 거른다.
  - 두 레인을 같은 크기로 보여 주는 것은 브랜드 표현을 위한 선택(AP)이다. 수량 차이는 숫자로 정직하게 보여 준다.
- B의 컬러웨이 아이디어는 **상세 페이지의 컬러 선택 영역**에서만 흡수한다(선택한 컬러웨이 두 색으로 상품 스테이지 배경 변경). 화면 전체 색 전환은 하지 않는다.
- "예뻐서"가 아니라 "Goal → 레인 → 비교 → 구매"의 흐름을 시각 언어가 그대로 안내하기 때문에 골랐다.

## 핵심 규칙 (선택안)
### Color [P]
| Token | 값(제안 근사치) | 용도 |
|---|---|---|
| `track-black` | #0A0D12 | 기본 표면 |
| `asphalt` | #161B22 | 카드·패널 |
| `lane-faster` | #FF5A1F | "Faster" 레인 — 컬러웨이 이름 Orange Glow에서 착안 |
| `lane-further` | #00D1C1 | "Further" 레인 — Energy Aqua에서 착안 |
| `signal` | #E4FF2E | 선택 상태·주 CTA — Illuminate Yellow에서 착안 |
| `cobalt` | #2E4BFF | 링크·보조 강조 — Cobalt Burst에서 착안 |
| `stage` | #EEF1F4 | 상품 스테이지(흰색 계열은 여기만) |
| `text` / `text-2` | #FFFFFF / #A9B1BD | 어두운 표면 위 텍스트 |

- 색 값은 **컬러웨이 이름에서 착안한 제안**이다. 공식 컬러값이 아니다(공식 값 미확인).
- 대비는 제작 단계에서 계산으로 검증한다. 레인 색 위 글자는 track-black만 쓴다는 가정이며, 검증 전이다.
- 레인 색은 Goal의 의미로만 쓴다(장식 금지). 색만으로 전달하지 않고 항상 "FASTER / FURTHER" 텍스트를 붙인다.

### Typography [P · 서체 조합은 AP]
- Display: 압축 이탤릭(후보 Barlow Condensed ExtraBold Italic) — 레인 제목, 모델명, 대형 수치
- UI·본문: Inter(Regular / Medium / SemiBold)
- Case Study 한글: IBM Plex Sans KR
- 세 서체 모두 Figma 가용성 확인 필요 [U]. 대체 후보: Saira Condensed, Archivo Narrow
- 수치는 단위와 함께 크게 쓴다(239 g · 8 mm · $210). 단위를 생략하지 않는다.

### Product Artwork [P]
- ASICS 상품 사진은 권리 미확인 → **사용하지 않는다(Fail Closed)**.
- 자체 제작 **측면 실루엣 벡터**를 쓴다. 모델 실물과 같은 모양이라고 주장하지 않고, "concept illustration"으로 표기한다.
- 실루엣의 색 블록은 실제 컬러웨이 이름의 두 색 조합을 따른다(예: White/Orange Glow).
- 기울기 −8°. 레인 경계를 넘는 겹침은 히어로·레인 헤더에서만 쓴다. 상품 그리드는 정렬을 유지한다.

### Graphic System [P]
- 레인 밴드: 폭 넓은 색 면 + 레인 번호(01 FASTER / 02 FURTHER)
- 사선 컷 12°: 섹션 전환에만
- 스펙 칩: Goal · Cushion · Support · Weight · Drop. 값은 실제 PDP 값만 쓴다.
- 화살표: 이동·CTA에만(장식 금지)
